How It Actually Works

Booking happens inside the conversation.

No forms. No buttons. The agent is given the doctor's real open slots, proposes one in plain language, and the moment the patient agrees, a hidden marker silently creates the appointment.

Engineering Choices

Every decision earns its place.

OpenRouter gateway

One key, every model. Runtime switch lets judges A/B models on the same prompt in one click.

Cheap stack

Qwen 3.x at ~$0.07–0.30 / 1M tokens → ~$0 demo cost. Premium Claude is a one-env-var swap.

BM25, not embeddings

At 31 docs, keyword + IDF matches cosine similarity — no vector store, no extra API call.

PWA, not native

Installs in 5s from a Chrome address bar on Android Go. 95% of native feel, 0% store overhead.

Python sidecar

Medical models ship PyTorch weights. Keep the Node API stateless; scale CV independently.

No accounts, minimal PII

Patient chat lives in localStorage only. No sign-up, no passwords — a phone number is the only identity needed to book.

Clinical Safety & Ethics

A medical copilot has to be trustworthy by construction.

🚨 Hard triage floor

Chest pain, stroke-like deficits, severe dyspnea, anaphylaxis, active hemorrhage can never be triaged below ORANGE — enforced in the prompt.

🎭 Held identity

Patients talk to "MA Agent." The system prompt refuses to reveal the model, provider, or stack under any circumstances.

📏 Calibrated uncertainty

"Most likely / possible / unlikely" — never false 95%-confidence. Never fabricates dosages, lab ranges, or citations.

🔒 Privacy by default

No persistent PII. Sessions in RAM with TTL, chat in localStorage. A non-dismissible disclaimer on every page.
